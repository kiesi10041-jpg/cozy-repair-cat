# 작은 수리점 0.6.1

**혼자 하기**에서 같은 고양이로 점검, 복원, 진열, 응대를 진행합니다. 가게 아래 목표 게이지 옆에는 현재 가능한 다음 행동이 표시됩니다. 첫 주 매출 650원을 달성하면 확장 승인서가 보관됩니다. 목표판에서 승인서를 사용해야 별관이 열립니다.

**부품 주문**에서 담기 한 번은 세 개 한 묶음입니다. 주문서에서 품목을 눌러 한 묶음씩 빼거나 구매 확정으로 결제합니다. 주문 한 건이 영업시간 20초 후 입구에 도착합니다.

**함께 하기**는 기존 Supabase 프로젝트를 사용합니다. 설정 절차와 SQL은 START-HERE.html 및 supabase/upgrade-v05.sql에 있습니다. 기존 config.js에 배포용 공개 연결 정보가 있다면 업데이트할 때 유지하세요.

구매·흥정: 손님/물품/테이블 장면 유지, 가격 제안과 물품 가치 탭 전환, 확정/거절 버튼 고정. 금액은 화면 안 숫자판으로 입력해 휴대폰 키보드 때문에 화면이 밀리지 않도록 합니다.

수리: 실제 도구 이미지(나사·드라이버·붓·천·돋보기 등)와 이미지 메뉴를 추가했습니다. 나사는 4번 터치하거나 원형 제스처, 세척/복원은 반복 터치 또는 문지르기로 조작합니다. 부품은 선택 후 목표 위치를 눌러 넣거나 끌어 놓을 수 있습니다. 작업 안내와 재료·인계는 위쪽 탭으로 전환합니다.

진열: 가격·진열 / 옮기기·회수 탭. 창고·인수: 두 줄 보관칸과 페이지 버튼. 설정: 저장·연결 / 시설·신호 / 물건 도감 탭. 도감은 네 품목씩 넘깁니다. 부품 주문도 6개 카드를 한 화면에 배치했습니다.

검증: 브라우저 안 844×390, 740×360 가로 뷰포트에서 거래 탭/숫자판 제안, 나사 네 번 터치, 수리 인계, 진열 탭, 주문, 창고/도감 메뉴 확인. 측정한 화면의 셸 높이와 스크롤 높이가 같고 주요 버튼이 화면 밖에 없음을 확인했습니다. 인수 화면의 기존 고정 이미지 높이와 보관칸 넘침도 수정했습니다. 실제 iPhone 기기 테스트는 포함하지 않습니다.

자동 검증: 8종 물품 각각 기존 제스처와 터치만으로 수리 완료, 잘못된 부품·방향 거절, 흥정·진열 렌더·전체화면 회귀 통과. 이전 캐릭터/물품/카운터 위치 및 픽셀 읽기 오류 수정 유지.

기존 config.js 연결값을 유지하세요. SQL 재실행이나 저장 초기화는 필요 없습니다. 파일을 교체한 뒤 0.5.11 표시를 확인하세요.
